For your Mac, and for your Terminal

What's eating your disk?

Drop a folder and dush shows you what's taking the space, biggest first — everything over 512 MB. It measures exactly like du, and it only looks. It never deletes.

Download for Mac Install the CLI

The app is free and needs macOS 26. The command-line tool is free and open source, and needs macOS 14.

  • 150,000 items measured in about a second, on an Apple silicon Mac. Faster than du on the same folder.
  • 34 cache, log and temporary locations checked by Caches & Temp. No folder to pick.
  • 0 files deleted, moved or changed. Ever. What to do about them is up to you.

dush for Mac

Drop a folder, see what's big.

Drag one or more folders onto the window or the Dock icon, or press ⌘O. dush counts every file — hidden ones and app bundles included — while you watch the numbers climb.

  • Caches & Temp needs no folder. It checks the caches and temp folders your Mac can rebuild on its own: system and app caches, logs, the Trash, and the caches of npm, Yarn, pnpm, Gradle, Cargo, Go, CocoaPods, Xcode, simulators and VS Code. Folders that don't exist or aren't safe are skipped, and a folder inside another folder counts once.
  • Downloads & Desktop scans the two usual suspects in one click.
  • Biggest so far: large files show up the moment they're found, folders as soon as they're measured. Press Esc to stop at any time.
  • Your options: a minimum size (100 MB, 512 MB, 1 GB, 5 GB or your own, like 1.5 GiB), files or folders only, skip node_modules, .git and other developer folders, or exclude names and patterns like *.xcarchive.

Safe to delete?

Ask your Mac, not a server.

Not sure what a folder is? Select it and ask. Apple Intelligence answers on this Mac, with a verdict, a one-line summary and what happens if you remove it. Then ask more, like Will I lose my SwiftUI previews?

dush gives the model only details about that item:

  • always its path, name, size and whether it's a file or a folder;
  • if you want, how many items are inside, the names and sizes of the 10 largest, and when it last changed;
  • never what's inside your files.

You can see what was sent under every answer. No server, no account, no key. Nothing leaves your Mac.

  • Check first It holds things you may want, like simulators.
  • Keep it Important data, like Xcode Archives with their debug symbols.
  • Protected by dush System folders, keys like ~/.ssh, iCloud Drive and whole personal folders get an answer at once. No AI asked, no bytes sent.

AI answers can be wrong. dush never deletes anything. If you decide to remove it, do it yourself in Finder.

Developer Caches

Your tools rebuild most of this on their own.

dush knows where your developer tools keep their caches and adds them up: 48.29 GB on a busy Mac. For each cache it tells you what it is, whether the tool rebuilds it on its own or it's worth a look first, and the command that tool suggests. You paste and run that command yourself, in Terminal. dush runs nothing.

  • Xcode build cache

    Build files and indexes. Xcode rebuilds them on the next build.

    Rebuilds itself

  • Unavailable simulators

    Simulators for iOS versions that are no longer installed, with the apps and data on them.

    Review first

    xcrun simctl delete unavailable

  • Old device support

    Debug symbols for iOS and watchOS versions your devices no longer run. The newest version of each device is left out.

    Rebuilds itself

  • Unused node_modules

    Packages in projects nobody changed in 90+ days, in your code folders, never in Documents or Desktop.

    Review first

  • npm, pnpm and Yarn

    Packages your package managers downloaded. They download them again when a project needs them.

    Rebuilds itself

    pnpm store prune

  • Gradle and Homebrew

    Dependencies, build outputs and old versions of what you installed.

    Rebuilds itself

    brew cleanup

Every card has Show in Finder, which selects exactly the cache's folders, and Copy Command when the tool has one — you paste it into Terminal and run it yourself.

The promises

dush only looks. It never deletes.

dush never deletes your files
It only looks. Removing something is always your choice, in Finder or Terminal. The only thing dush ever removes is its own scan history.
No tracking, no profiling
No analytics, no telemetry, no identifiers. Your scans never leave this Mac.
Offline, always
dush never uses the network. Apple Intelligence answers on this Mac, so nothing leaves it.
No accounts
No sign-in, no email, no cloud sync.
No in-app purchases
Free. No subscriptions, no Pro version, no ads.

Not just words: dush's own tests fail if the code ever reaches the network, deletes a file it doesn't own, or grows a delete button.

In the Terminal

The same engine, in your Terminal.

dush started as a command-line tool, and it still is one. The app and the CLI share the same engine, so they report the same sizes for the same folder, down to the byte. Install it with Homebrew:

brew tap andre_rori/tap https://codeberg.org/Andre_Rori/homebrew-tap.git && brew install andre_rori/tap/dush

Try it

# The caches and temp folders, no path needed
dush

# Your home, files over 1 GB, the top 10
dush ~ --min-size 1GB --files-only --top 10

# Skip node_modules, .git, DerivedData and friends
dush ~/Code --exclude-dev

# A report for your scripts
dush ~/Library/Developer --json > developer.json
